# 应用配置

`configs/` 保存可共享的应用配置与说明，随学员材料同步。

Lab 06 按 [操作步骤](../labs/06-evals-release/LAB.md)在 `configs/local/lab06/` 创建基线、候选配置、Prompt、DSL 和共用评测输入。运行报告保存在 `reports/local/lab06/`。

`configs/local/` 保存本机实际参数和应用导出，不提交，也不从课程源码同步到学员目录。学员在自己的目录中生成配置；课程初始模板位于 `labs/06-evals-release/`。API key 等凭据继续保存在本地 `.env`。
